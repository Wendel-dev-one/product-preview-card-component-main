# Product Preview Card Component

Este projeto é uma solução para o desafio [Product Preview Card Component](https://www.frontendmentor.io/challenges/product-preview-card-component-GO7UmttRfa) do Frontend Mentor.

## 📦 Sobre o Projeto

Um componente de cartão de produto responsivo, desenvolvido com HTML e CSS, seguindo boas práticas de acessibilidade, responsividade e organização de código. O layout é fiel ao proposto pelo desafio, com adaptação para dispositivos móveis e desktop.

## 🖼️ Layout
- Desktop e mobile responsivo
- Imagem do produto adaptável via `<picture>` e `<source>`
- Tipografia e cores conforme o design original

## 🚀 Tecnologias Utilizadas
- HTML5 semântico
- CSS3 (com uso de variáveis, rem, BEM e media queries)
- Google Fonts (Fraunces, Montserrat)

## 📁 Estrutura de Pastas
```
├── css/
│   ├── reset.css
│   ├── style.css
│   ├── variables.css
│   └── responsive.css
├── images/
├── design/
├── index.html
└── README.md
```

## 💡 Boas Práticas Aplicadas
- Classes CSS padronizadas (BEM)
- Unidades relativas (`rem`) para acessibilidade
- Imagem principal com `<picture>` para responsividade
- Separação de estilos por responsabilidade
- Atributos `alt` descritivos para imagens

## 📱 Como Visualizar
1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
